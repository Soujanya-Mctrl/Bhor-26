# Bhor ’26

A literary and arts magazine showcase built with the Next.js App Router, TypeScript, and Tailwind CSS. The home page follows a flower opening into the current issue reveal. The /issue route contains a labelled reading sample.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. For a production check, run npm run build and npm start.

The cover and archive artwork are design studies. The published magazine, previous issues, and final credits can replace them once supplied. Artwork and fonts are served locally. The font files and corresponding SIL Open Font License notices are in app/fonts/.
